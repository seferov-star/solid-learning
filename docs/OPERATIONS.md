## Обновление и откат

1. Проверить тесты и дождаться CI. Сборка Pages публикуется отдельно, API image выгружается артефактом api-image.
2. tools/download-image.py скачивает OCI-архив. Перед загрузкой в Docker сверить SHA256 локального файла и копии VPS.
3. Снять backup через docker compose exec -T api node --import tsx server/manage.ts backup.
4. Обновить ACADEMY_IMAGE и выполнить docker compose up -d только для этого проекта. Проверить health/HTTPS и вход.
5. Для отката вернуть предыдущий тег. При несовместимой миграции остановить api, отдельно сохранить текущую БД со всеми WAL/SHM, восстановить резервную копию, затем запустить предыдущий образ. Не восстанавливать БД поверх работающего приложения.

## Проверки

Тесты Terra: ядро/API, 20 одновременных клиентов, резервирование и восстановление. Браузер: регистрация/одобрение, разграничение доступа, допуск, нерешённые, пауза/продолжение, история и мобильная ширина. Это учебный учёт, а не прокторинг: исходные учебные банки опубликованы в прежней игре.

Прямой маршрут из тестовой сети обрывал крупные ответы около 16 КБ. По согласованию владельца API проксируется Cloudflare. Пользователи и данные хранятся на VPS, но Cloudflare обрабатывает HTTPS-запросы к API. При сетевых сбоях браузер показывает ошибку вместо бесконечного ожидания; принятый ответ восстанавливается с сервера.
