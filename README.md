# Солид — серверный учебный центр

Независимая копия. Исходная игра и её Pages не изменяются.

Node 24: `npm ci`, `npm test`, `npm run build`. API: `npm run server`; frontend: `npm run dev -- --port 5173`. Для локальной разработки origin должен совпадать: `WEB_ORIGIN=http://localhost:5173`; `VITE_API_URL=http://localhost:8080`.

Продакшен: https://seferov-star.github.io/solid-learning/ (GitHub Pages), https://37-27-22-177.sslip.io (API на HqServ, временный адрес). Настройки входят в compose.yml. База и секреты не публикуются. Bootstrap: `node --import tsx server/manage.ts bootstrap` записывает пароль только в защищённый файл data/bootstrap.txt. При первом входе обязательна смена. Пароль в логи не выводится.

Регистрация ожидает одобрения. Все активные пользователи видят все темы. Админ управляет статусами, ролями, временными паролями, допусками, результатами и CSV. Архивирование сохраняет историю. Сессии отзываются при блокировке, смене роли/пароля. Фронтенд использует Bearer-токен серверной сессии в sessionStorage без сторонних cookies. Разрешён WEB_ORIGIN=https://seferov-star.github.io; изменения требуют CSRF. Токен отзывается при выходе/блокировке/смене пароля, не передаётся в URL.

Экзамен: auto — все вопросы и кейсы решены верно хотя бы раз в тренировках. Экзаменационные ответы не дают допуск. open/closed — ручное решение; отсутствие экзамена у темы не обходится. Изменение допуска влияет на новые запуски; блокировка аккаунта прекращает текущие попытки.

Нерешённые: вопросы/кейсы без правильного тренировочного ответа; повторная ошибка не отменяет зачёт. Попытки хранят версию банка и порядок вариантов. Один активный запуск на аккаунт. Ответы проверяются сервером; повтор не начисляет бонус дважды. Таймер и пауза серверные. Исходные банки уже опубликованы в старой учебной игре: система обеспечивает учёт прохождений, не является прокторингом.

Будущее расширение: внутренний JSON-формат schemaVersion=1 описан в server/content.ts. Новые банки валидируются и версионируются. Загрузка и редактор через админку в v1 не включены. Не меняйте ID при редакционной правке; при изменении проверяемого смысла или правильного ответа нужен новый ID.

Резервная копия: `node --import tsx server/manage.ts backup`. Используется backup API SQLite (включает WAL); 14 ежедневных и 4 еженедельных копии. Восстановление — остановить только api, сохранить текущую БД, вернуть проверенную копию, запустить api. Никогда не копировать работающую SQLite без WAL или backup API.

Текущий API через sslip.io обращается напрямую к тому же VPS с HTTPS, без Cloudflare. Новый frontend не обращается к hqserv.ru. API: Cache-Control: no-store. Сертификаты автоматически обновляются таймером. Адрес sslip.io выбран владельцем как временный; доступность из рабочей сети проверяется отдельно.

Телефонный экзамен: отдельный банк 40 заданий по предоставленному материалу; в попытке 30, все 19 тем, по 15 medium/hard, 25 минут, порог 80%. Правильные ответы/разбор/цитаты только после завершения. Тренировочный банк 19 вопросов + 38 кейсов и условия допуска сохранены. Источник и импорт: tools/import-phone-exam.py, web/src/learning/phone-exam.json; цитаты сверяются с исходным DOCX по хешу и тексту.
